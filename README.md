# NASA Space Facts

## Project Idea

NASA Space Facts is a simple educational project that provides interesting facts about NASA and space exploration. The project can help people learn more about space in an easy and organized way.

## Technologies / Tools Used

- GitHub
- Markdown
- HTML

## How to Run / Use the Project

1. Open the project repository.
2. Open the main HTML file.
3. View the NASA and space facts displayed on the page.
